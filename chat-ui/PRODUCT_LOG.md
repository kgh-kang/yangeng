# 모아 — 제품 개발 로그

채팅형 AI 서비스 "모아"를 시안(A/B/C)에서 실제로 쓸 수 있는 제품(`app/`)으로 키우는 과정의 기록입니다.
라운드마다 **평가 → 개선 → 검증(E2E 테스트·화면 캡처)** 순서로 진행합니다.

## 실행 방법

```bash
cd chat-ui
python3 -m http.server 8765     # http://localhost:8765/app/
node tests/e2e.js               # E2E 테스트 (Playwright 필요)
```

- API 키가 없으면 **데모 모드**로 동작합니다(미리 준비된 답변).
- 설정에서 Anthropic API 키를 넣으면 공식 SDK(`@anthropic-ai/sdk`, 브라우저 ESM 빌드)로 Claude와 스트리밍 대화합니다.
  키는 그 브라우저의 localStorage에만 저장됩니다. **개인용·프로토타입용** 구성이며, 여러 사용자가 쓰는 서비스는 키를 서버에 두고 같은 요청을 서버에서 보내야 합니다.
- 실제 SDK 경로 테스트: SDK를 esbuild로 묶은 파일을 `SDK_BUNDLE=...`로 넘기면 CDN·API 요청을 가짜 서버로 대체해 검증합니다.

## 구조

| 파일 | 역할 |
|---|---|
| `app/index.html` | 화면 뼈대 (사이드바 · 대화 시트 · 미리보기 패널) |
| `app/app.css` | 토스 스타일 토큰과 컴포넌트, 라이트/다크, 반응형 |
| `app/js/markdown.js` | 스트리밍 안전 마크다운 렌더러 (표·체크리스트·코드·인용, 모든 입력 이스케이프) |
| `app/js/store.js` | 대화·설정 저장 (localStorage, 용량 초과 시 오래된 이미지부터 정리) |
| `app/js/api.js` | Claude SDK 스트리밍 / 데모 응답기, 오류를 사용자 문구로 변환 |
| `app/js/app.js` | 렌더링, 대화 흐름, 첨부, 시트·다이얼로그, 단축키 |
| `tests/e2e.js` | E2E 테스트 |

## 라운드 1 — 시안을 제품으로

**출발점 평가 (시안 3종)**

| 항목 | 상태 | 문제 |
|---|---|---|
| 실제 AI 연결 | ✗ | 데모 응답만 있음 |
| 대화 저장·전환 | ✗ | 최근 목록이 가짜, 새로고침하면 사라짐 |
| 대화 관리 | ✗ | 이름 변경·삭제·검색 없음 |
| 답변 다루기 | △ | 복사만 가능, 수정·다시 생성이 형식적 |
| 결과물 | △ | 패널(B)은 정적 목업 |
| 첨부 | ✗ | 버튼만 있음 |
| 오류 처리 | ✗ | 없음 |

**방향 결정**: 시안 C(토스 결합)를 기본 스타일로 하고 B의 결과물 패널, A의 "빈 화면에선 가운데" 흐름을 합친다.

**구현**
- Claude 연결: 공식 TypeScript SDK 브라우저 빌드, `claude-opus-5-5` 기본, 모델 3종(깊게/기본/라이트), 답변 깊이(effort), 맞춤 지침(system), 거절 시 서버 측 기본 폴백(`fallbacks: "default"`)
- 대화: localStorage 저장, 날짜별 그룹(고정됨/오늘/어제/지난 7일…), 검색, 이름 변경, 고정, 마크다운 내보내기, 삭제 확인
- 메시지: 스트리밍(rAF로 묶어서 그리기), 중지, 다시 생성, 내 메시지 수정 후 재전송(↑ 키로 마지막 메시지 수정), 복사, 좋아요/별로예요
- 결과물: HTML/SVG 코드 블록 → 샌드박스 iframe 미리보기 + 코드 탭
- 첨부: 파일 선택·붙여넣기·끌어다 놓기, 긴 변 1568px로 자동 축소, 최대 5장
- 오류: 잘못된 키 → "설정 열기", 권한 없음 → "모델 바꾸기", 속도 제한·네트워크·서버 오류 문구, 거절(refusal)·길이 초과(max_tokens) 안내
- 단축키: Ctrl/⌘ K 검색, Ctrl/⌘ Shift O 새 대화, Esc 레이어·패널 닫기 / 응답 중지

**검증**: E2E 15개 통과 (데모 11 + 실제 SDK 경로 4: 요청 형식, Haiku 분기, 401, refusal/max_tokens)

**자체 리뷰에서 고친 것**: `hidden` 속성이 CSS `display`에 덮여 빈 화면에 "맨 아래로" 버튼이 보이던 문제, 내 메시지 아래 투명한 액션 줄 때문에 생긴 큰 간격, 데모 HTML의 `\n` 노출
