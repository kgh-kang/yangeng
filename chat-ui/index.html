모아 채팅 UI 시안

채팅형 AI 서비스 "모아" 작업물이에요. 위의 완성 앱을 먼저 써 보세요. 아래는 처음 만든 HTML 껍데기 시안 3종입니다. 세 시안 모두 같은 chat-shell.js로 전송, 스트리밍 응답, 새 대화, 사이드바, 모델 선택, 라이트/다크 전환이 동작합니다.

완성 제품모아 앱 열기시안 C를 바탕으로 만든 실제 동작하는 채팅 앱이에요. 대화 저장·검색, 웹 검색, 이미지 첨부, 결과물 미리보기(버전), 음성 입력, 백업을 지원해요. API 키가 없으면 데모 모드로 동작해요. 열기 →

초기 시안

시안 A
클래식따뜻한 종이 톤과 세리프 인사말. 빈 화면에선 입력창이 가운데, 대화가 시작되면 아래로 내려갑니다.
시안 B
스튜디오아이콘 레일 + 대화 + 오른쪽 아티팩트 패널. 결과물을 미리보기/코드로 나란히 확인하는 작업형 레이아웃입니다.
시안 C
토스 결합회색 바탕 위 흰 시트, 굵은 왼쪽 정렬 헤드라인, 컬러 타일 리스트, 파란 말풍선과 바텀시트 모델 선택.
실제 API 연결: ChatShell.setResponder(async function* (text, history) { … yield 토큰; }) 로 데모 응답기를 교체하세요.
