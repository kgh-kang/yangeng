# 양 번역기 — 문법 규칙 레퍼런스 (GRAMMAR)

> 양박사네 공학영어 강의의 **5형식 + Reed-Kellogg** 체계를, `parser.js`/`renderer.js`가
> 구현한 규칙으로 정리한 정식 스펙 문서. 기능 추가/수정 시 **이 문서도 함께 업데이트**한다.
> 작업 이력은 [WORKLOG](WORKLOG.md), 갭 분석은 Obsidian 볼트 참고.

---

## 1. 핵심 이론 (양박사 체계)

### 1.1 동사의 양식 2가지
| 양식 | 자/타 | 형식 | 한국어 동사유형 | 어미 |
|------|-------|------|----------------|------|
| **존재 양식**(자동사) | 자동사 | 1형식 | 자존형 | **'있다'** |
| | | 2형식 | 의존형 | **'이(되)다'** |
| **소유 양식**(타동사) | 타동사 | 3형식 | 소유형 | **'하다'** |
| | | 4형식 | 수여형 | **'주다'** |
| | | 5형식 | 복합형 | **'이다'고 + '하다'** (= '이게/되게 하다') |

이 매핑은 **고정**이다(13-1 마스터 키). 형식이 정해지면 한국어 동사유형이 1:1로 결정된다.

### 1.2 문장의 주성분 3가지
- **명사**: 주어(Who) / 목적어(What) / 보어
- **동사**: 형식을 결정 — 성분별로 나누기(`/`)
- **형용사**: 주성분 형용사(명사를 **간접** 수식, 보어) ⇔ 종속성분 형용사(명사를 **직접** 수식)

### 1.3 부사의 4형태
**When형 / Where형 / How형 / Why형** (시간·장소·방법·이유).

### 1.4 형식 판별 알고리즘
1. **동사를 찾는다.**
2. 동사 뒤 **명사군 개수**를 센다.
3. **이퀄(=) 관계**로 보어/목적어를 구분한다.
   - 동사 뒤 명사 1개: 주어와 **이퀄**이면 2형식(보어), **아니면** 3형식(목적어).
   - 명사 2개: "~에게 ~을"(이퀄 아님) → 4형식 / O=OC(이퀄) → 5형식.

예) `She made a good wife` → She=wife → **2형식** / `She made a good meal` → She≠meal → **3형식**.

## 2. 형식별 정의

| 형식 | 구조 | 예 |
|------|------|-----|
| 1형식 | 주어 / 동사 | They came here. / The stars shine. |
| 2형식 | 주어 / 동사 / 주어보어 | He is a diligent person. / Computers are fast. |
| 3형식 | 주어 / 동사 / 목적어 | I saw the stars. / They study English. |
| 4형식 | 주어 / 동사 / 간접목적어 / 직접목적어 | He bought her the book. |
| 5형식 | 주어 / 동사 / 목적어 / 목적어보어 | I make him a diligent person. |

**보어 표기**: 형용사 보어·목적격보어는 **그대로 표기**(교재 reading 지문). 예) `is simple` → 보어 simple / `made her happy` → OC happy.
**생략어 복원**: 명사가 실제 생략된 경우만 `(that)`(목적격 관계사)·`(ones)`(지각·사역 to부정사 OC)·`(one)`(with 부대상황) 복원.

## 3. 동사 세분류 (parser.js 집합)

| 집합 | 역할 | 대표 동사 |
|------|------|-----------|
| `BE` | be동사 | am is are was were be been being |
| `LINKING` | 연결동사(2형식) | be, seem, become, remain, look, sound, taste, smell, feel, get, turn, grow… |
| `PURE_LINKING` | 순수 연결(항상 2형식) | be, seem, become, remain |
| `DITRANSITIVE` | 4형식 수여동사 | give send tell show teach buy bring offer lend pay… |
| `OC_CONSIDER` | 5형식 간주동사 | call name make find keep consider think believe elect declare… |
| `CAUSATIVE` | 사역동사(원형부정사 OC) | make let have set |
| `PERCEPTION` | 지각동사(원형부정사 OC) | see watch hear feel smell notice observe |
| `INDUCTIVE` | 유도동사 | help(원형부정사) / get(to부정사·과거분사) |
| `OC_GENERAL` | 5형식 일반(to부정사 OC) | tell ask want expect advise allow cause enable force order persuade require… |
| `TO_INF_OBJ` | to부정사를 **목적어**로 취함(3형식) | want need like decide hope plan try begin learn… |
| `TRANSITIVE`/`EXTRA_TRANS` | 일반 타동사(공학 동사 포함) | study use develop process store generate compute collect steer track pinpoint… |
| `INTRANS_ONLY` | 자동사 전용 | rise arrive happen shine walk run wander rely… |
| `AMBI_VERBS` | 자·타 양용 | grow change move stop succeed fail pass win lose… |

## 4. 구현된 규칙

### 4.1 to부정사 (세션 10)
- **명사적 목적어 → 3형식**: `I want to go` (동사 ∈ `TO_INF_OBJ`, 뒤 명사 없이 to부정사).
- **주어 → 2형식**: `To learn is important` (문두 to+동사, 콤마 없을 때).
- **5형식 OC(to부정사)**: `I want him to go` (동사 ∈ `OC_GENERAL`/`OC_CONSIDER`/`get`).
- **부사적 용법 유지**: `I came to help you` = 1형식(자동사 + 목적의 부사구).

### 4.2 원형부정사 5형식 (세션 9·11)
- 사역(make/have/let)·지각(see/hear…)·help는 **원형부정사** OC: `I make you study`, `help me carry`.
- **사역/지각은 to부정사를 OC로 안 취함** → `have a way to keep` = 3형식(to부정사는 way 수식).
- **get은 원형부정사 안 취함** → `get a prize` = 3형식 / `get him to go` = 5형식(to부정사).

### 4.3 수동태 (세션 8·9) — **무조건 2형식**
- `be + 과거분사` = 2형식(be=동사, 과거분사=형용사 보어). 형식 강등 3→2/4→2/5→2.
- 진행·완료 수동: `is being p.p.`, `has been p.p.`, `had been p.p.` 모두 2형식.
- **원형부정사 to복원**: 지각·사역 수동은 능동 원형부정사가 to부정사로 복원 — `They saw him go → He was seen **to go**`.
- **분사형용사 구분**: by행위자 없는 감정형용사(tired/interested 등 `EMOTION_ADJ`)는 수동 아닌 일반 2형식 보어.

### 4.4 복문(종속절) (세션 1·10)
- **명사절**: that/whether/if + 동사 바로 뒤(목적어 자리), 간접의문(의문사절).
- **형용사절(관계대명사절)**:
  - 목적어 수식(기존): `I saw the stars **that** were shining`.
  - **주어 수식**(세션10): `The man **who** runs is fast` → 주절+관계절 분리.
  - **목적격 관계사 복원**(세션16): 관계사가 목적어면 절에 `(that)` 복원 → 형식 재판정.
    `the Army made **(that)** famous` = 5형식 / `the book I read **(that)**` = 3형식.
- **부사절**: 종속접속사(because/although/if/when/while/since…).
  - **문두 부사절**(세션10): `When the system fails, we restart it` (콤마 구분).
- 각 절은 독립 분석되어 절 유형 + 형식 라벨이 패널에 표시된다.

### 4.5 句동사 (phrasal verb) (세션 1)
- `take in / pull out / break down / pick up …` = 동사+불변화사 1동사(`PHRASAL` 사전). 형식은 본동사 기준.

### 4.6 기타 보정 (세션 10)
- **시간 부사구**: `every day / this morning / yesterday` → 목적어 아닌 부사구(`TIME_*`).
- **비교구문**: `as ADJ as` / `ADJ-er than` / `more ADJ than` → 형용사 보어(2형식).
- **순수 부사 보어 아님**: `go there / is here` = 1형식(here/there/now는 수식어).
- **관용구**: `make a success of ~` 등 of전치사구가 붙은 make류 → 3형식.
- **호격**: `Ladies and gentlemen, be ambitious!` → 콤마 앞 호격 건너뛰고 명령문 파싱.

### 4.7 동명사 (세션 10·11)
- **목적어**: `I enjoy reading` = 3형식.
- **주어**: `Relying on satellites … makes the system precise` = 5형식(동명사 주어구).

## 5. Reed-Kellogg 작도 규칙 (renderer.js)

- **선 색**: 주절·본동사 baseline = **빨강**(`_RK.line`) / 종속절·수식어·받침대 = **검정계열**(`_RK.sub`).
- **구분선**: S–V 전체관통 수직선 / V–O 반선(half) / 보어·OC 사선(`\`).
- **수식어**: baseline 아래 — 단어 수식어(관사·형용사·부사)는 `\`사선+단어로 매닲.
- **전치사구 = ㄴ(L자) 받침**: 본선에서 세로 다리 → 가로 받침선 위에 **`전치사 목적어`를 함께**(둘 사이 구분선 없음). 목적어 수식어는 목적어 아래 `\`. 예) `from electronics companies` → ㄴ에 `from companies`, `\electronics`(companies 수식). **분사구(`part`)·to부정사구(`inf`)** 도 동일한 ㄴ 받침. (구현: `_rkPhrase`는 세로다리+가로받침에 라벨·목적어를 함께 올리고, `_rkMods`의 `legX`로 본선 연결선을 ㄴ 다리에 정렬, `_rkClause`는 수식어 블록을 셀 폭 안에 가둬 옆 칸 침범 방지.)
- **생략어 복원**: `(one)/(ones)/(a)/(to be)` 등은 이탤릭·회색으로 표시.
- 텍스트 폭은 canvas `measureText`로 동기 측정해 좌표 정확 배치(픽셀 드리프트 없음).

## 6. 알려진 한계 (시험 시 직접 확인 권장)

1. **동명사 보어 ↔ 진행형 모호**: `My hobby is reading`(보어) vs `He is reading`(진행) 구분 불가.
2. **DB에 없는 희귀 동사**: 주어-동사 오인 가능(흔한·공학 동사는 대량 보강).
3. **문두 부사적 to부정사**: `To find …, soldiers relied …`는 주어 오인 가능(미완).
4. **`keep her room clean`류**: 목적격/소유격 동음인 `her`+NLP 비결정성으로 5형식↔2형식 흔들림(`his/the/him`은 정상).
5. **무관사 이중 명사 4형식**: `gives students homework`처럼 관사·대명사 없는 두 명사는 IO/DO 경계 분리 실패(`gives the students homework`·`gives them homework`은 정상).
6. **중첩 분사구문 + to부정사 형용사적 수식**: `… way to keep from getting lost, using a technology …`처럼 콤마로 이어지는 분사구문과 명사 수식 to부정사는 한 수식어로 뭉쳐 렌더(형식 판정은 정상, 세부 받침대는 근사).
